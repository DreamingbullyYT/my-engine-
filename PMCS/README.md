# Dream Engine — PMCS

Persistent project memory for Dream Engine. Keep these documents separate; do not collapse them into one large file.

## Source of truth
1. Explicit user decisions recorded in DECISIONS.md
2. Current implementation and tests in CURRENT_STATE.md
3. Requirements in PROJECT_MEMORY.md and RULES.md
4. Architecture and roadmap are planning documents until verified by code/tests

## Documents
- PROJECT_MEMORY.md — purpose, requirements and scope
- CURRENT_STATE.md — verified repository state and next actions
- RULES.md — mandatory engineering rules
- ARCHITECTURE.md — proposed module boundaries and contracts
- DECISIONS.md — accepted decisions and open questions
- ROADMAP.md — milestones and completion criteria
- TECHNICAL_AUDIT.md — research candidates and evidence still needed
- AI_HANDOFF.md — concise instructions for the next work session
- ANDROID_INTEGRATION.md — AndroidX GameActivity host-app setup and backend contract

Status labels: ACCEPTED, PROPOSED, RESEARCH, IMPLEMENTED, VERIFIED, BLOCKED. Never call something VERIFIED without reproducible evidence.
