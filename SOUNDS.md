# Lista de sunete (v1)

Format: `.ogg` (efecte scurte și muzică), mono pentru efecte. Cale: `sounds/<categorie>/<id>.ogg`, muzică în `sounds/music/`.

## Surse sigure (fără copyright strike)

| Sursă | Licență | Note |
| --- | --- | --- |
| Kenney.nl (pachete audio) | **CC0** | cele mai sigure; fără atribuire |
| OpenGameArt.org | filtrezi doar **CC0** | evită CC-BY-NC / NC (interzis comercial) |
| Freesound.org | filtrezi doar **CC0** | verifici licența fiecărui fișier |
| Pixabay (sunete și muzică) | licență Pixabay | fără atribuire; verifică termenii la zi |
| Sonniss GDC Game Audio Bundle | royalty-free | pachete mari, gratuite, de uz comercial |
| incompetech (Kevin MacLeod) | CC-BY | **cere atribuire** în credite |

Reguli: **CC0 = fără griji**; CC-BY = pui creditul în joc; **fără NC**; nu folosi sunete extrase din alte jocuri sau muzică de pe YouTube/Spotify. Păstrează un `CREDITS.md` cu sursa și licența fiecărui fișier.
Alternativă: pot genera eu **placeholdere sintetizate din cod** (ale tale, fără licență), pe care le înlocuiești treptat.
